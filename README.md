# 🎮 Digimon Level System

Sistema de progressão de níveis desenvolvido em **Roblox Studio**, inspirado na experiência e nas mecânicas de progressão do **Digimon Aurity**, um jogo de Digimon que foi descontinuado.

## 📖 Sobre o projeto

Este projeto está sendo desenvolvido **em equipe** como uma iniciativa independente inspirada na nostalgia de **Digimon Aurity**, um jogo de Digimon que marcou a experiência de seus jogadores antes de ser descontinuado.

A proposta é desenvolver um novo projeto inspirado em algumas das ideias e mecânicas que fizeram parte da experiência do jogo, ao mesmo tempo em que utilizamos o desenvolvimento para aprimorar conhecimentos em **programação, desenvolvimento de jogos e criação de sistemas multiplayer**.

> Este projeto é independente e não possui vínculo oficial com Digimon Aurity ou com suas respectivas propriedades intelectuais.

## ⚔️ Sistema de experiência

O sistema implementa uma mecânica de progressão baseada em **experiência (XP)**.

Ao derrotar uma entidade humanoide, o jogador gera **coletáveis de XP** no local da derrota. Esses coletáveis podem ser recolhidos pelo jogador e adicionam experiência ao seu progresso.

O fluxo principal funciona da seguinte forma:

**Derrotar entidade → Gerar XP → Coletar XP → Acumular experiência → Subir de nível**

A quantidade de XP necessária para avançar aumenta progressivamente conforme o nível do jogador, criando uma curva de evolução.

## ⚙️ Funcionalidades

- 📈 Sistema de níveis e experiência (XP)
- ✨ XP gerado através da derrota de entidades
- 🟢 Coletáveis de experiência
- 🎲 Diferentes quantidades de XP através de sistema de probabilidade
- 📊 Progressão de XP baseada no nível
- 🆙 Sistema de Level Up
- ❤️ Evolução de atributos conforme o nível
- 🖥️ Atualização do HUD em tempo real
- 🎨 Efeitos visuais para os coletáveis
- ⚔️ Integração com sistema de combate
- 👥 Suporte a múltiplos jogadores

## 🛠️ Tecnologias

- **Luau**
- **Roblox Studio**
- Roblox API
- RemoteEvents
- CollectionService
- TweenService

## 🎯 Objetivo

Além de ser uma homenagem à nostalgia de um jogo que fez parte da comunidade de Digimon, o projeto tem como objetivo proporcionar uma experiência prática de **desenvolvimento em equipe**, aplicando conceitos de programação, lógica, sistemas de progressão, multiplayer e desenvolvimento de jogos.
